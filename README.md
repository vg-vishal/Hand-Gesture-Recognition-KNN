# 📌 Project Overview

This project presents an **AI-Based Hand Gesture Recognition System** using the **MPU6050 IMU Sensor** and the **K-Nearest Neighbors (KNN)** machine learning algorithm.

The MPU6050 sensor captures acceleration and gyroscope data generated by different hand movements. These sensor values are processed and classified using a trained KNN model to recognize predefined hand gestures.

The project demonstrates the integration of **Embedded Systems** and **Artificial Intelligence** for real-time gesture recognition.

# 🤖 Machine Learning Algorithm

## K-Nearest Neighbors (KNN)

KNN is a supervised machine learning algorithm used for classification.

The algorithm classifies a new hand gesture by comparing it with previously collected gesture samples and selecting the majority class among the nearest neighbors.

---

# 📊 Sensor Features

The MPU6050 provides six input features:

- Ax (Acceleration X)
- Ay (Acceleration Y)
- Az (Acceleration Z)
- Gx (Gyroscope X)
- Gy (Gyroscope Y)
- Gz (Gyroscope Z)

These values are used as input to the KNN classifier.

# ⚙️ Working Procedure

1. Collect sensor data from the MPU6050.
2. Store the collected data in a dataset.
3. Train the KNN model using the dataset.
4. Read new sensor values.
5. Predict the hand gesture.
6. Display the recognized gesture.
